## 🔭 About

AI coding agents are becoming a new way of working.

They can plan tasks, write code, use tools, run commands, communicate with other agents, and work together as a team.

But today, most of that process is hidden behind terminal output.

**AgentSpyglass makes it visible.**

It provides a visual way to understand what agents are doing in real time — not just for developers, but for anyone curious about how AI agents actually work.

> If someone asks you what an AI coding agent does, you should be able to show them.

## ✨ Features

* 🤖 Visualize AI agents and their activity
* 🛠️ See tool calls as they happen
* 📋 Follow tasks and their progress
* 💬 Visualize agent messages and interactions
* ⚡ Watch agent workflows in real time
* 🔌 Connect AI coding agents through integrations

## 💭 Why AgentSpyglass?

The idea came from a very simple problem.

I wanted to show my parents what it was like to work with AI agents.

It went terribly.

I opened the terminal and tried to explain what all the agents, commands, tool calls, and output meant. It was technically accurate, but it wasn't something they could really understand — or find interesting.

That's when AgentSpyglass started.

If agents are becoming a new way of working, there should be a better way to **show people what they're actually doing**.

That's what AgentSpyglass is for.
